## MEDIUM FINDINGS

### F-07: IP Allowlist Claim Incorrect

**Claim:** "IP Allowlist middleware EXISTS but NOT MOUNTED in main.py"

**Actual:** It IS conditionally mounted:

```python
if settings.ip_allowlist:
    app.add_middleware(IPAllowlistMiddleware, allowlist_raw=settings.ip_allowlist)
```

**Impact:** Misleads about security posture. It's mounted when configured.

### F-08: OpenAPI Generator Script Missing

The committed `docs/backend/openapi.yaml` is valid (6,494 lines, OpenAPI 3.1.0).
But the test file references `scripts/gen_openapi.py` which **does not exist**.
The spec was generated but the generator was never committed.

### F-09: Case Sensitivity Bug in OpenAPI Test

`test_openapi_spec.py` references `docs/Backend/openapi.yaml` (capital B) but
the actual path is `docs/backend/` (lowercase b). Works on Windows but would
break on Linux CI. The test has a `skipif` guard so it degrades gracefully.
