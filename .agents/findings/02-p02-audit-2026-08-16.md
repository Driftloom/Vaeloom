## HIGH SEVERITY — WRONG CLAIMS (5)

### H1: 6 memory types that don't exist in codebase

- **File:** `docs/phases/mvp-p02/14-data-feasibility.md`
- **Claim:** "Six memory types: Profile, Document, Career, Episodic, Preference,
  Working"
- **Reality:** Code has 22 types in
  `apps/api/src/api/schemas/memory_types.py:6-28`: Person, Organization,
  Project, Skill, Achievement, Education, Experience, Certification,
  Publication, Patent, Award, Meeting, Task, Goal, Preference, Constraint,
  Insight, Connection, Location, Event, Document, Conversation. Only
  `Preference` and `Document` match by name. `Career`, `Episodic`, `Working` do
  not exist in the enum.
- **Evidence:** `schemas/memory_types.py:6-28`
- **Status:** FIXED — replaced with actual 22 types, updated table rows

### H2: Approval middleware claimed but doesn't exist

- **File:** `docs/phases/mvp-p02/17-decision-implications.md`
- **Claim:** "Approval middleware required for all consequential actions"
- **Reality:** No `ApprovalMiddleware` exists in `main.py`. `ApprovalManager` is
  a REST service (`services/approval.py`), not HTTP middleware. No approval
  check in `orchestrator/loop.py` — agents execute directly.
  `has_approval=False` hardcoded at `loop.py:83`.
- **Evidence:** `main.py` (no ApprovalMiddleware), `loop.py:83`
- **Status:** FIXED — changed to "Approval service exists (not enforced in
  orchestrator loop)"

### H3: Feature flags AUTO-01/02/03 are fictional

- **File:** `docs/phases/mvp-p02/17-decision-implications.md`
- **Claim:** "Feature flags AUTO-01/02/03; kill switches"

- **Status:** FIXED — changed to "Gmail agent supports trigger param; no BullMQ
  cron job wired yet"

- **Evidence:** `services/encryption.py:11-33`
- **Status:** NO FIX NEEDED — no encryption claims in P02 deliverables

### M4: memory_records.type described as enum, is String(50)

- **Claim:** "memory_records.type enum with six values"

- **Evidence:** `models/schema.py:268`

  MEMORY_TYPE_REGISTRY has 22 entries)"

## Remaining Codebase Gaps (Not P02 Deliverable Issues)

are NOT documentation errors — they're implementation gaps:

   hardcoded. Approval service exists but orchestrator never checks it.

   cron job registers Gmail handlers.
3. **Encryption status-only** — `encryption.py` only checks if key is set,
   doesn't actually encrypt anything.
4. **TenantMiddleware not mounted** — Code exists but not in `main.py`.
5. **IP Allowlist middleware not mounted** — Code exists but not in `main.py`.
6. **Prometheus metrics commented out** — `main.py:135-136`.
