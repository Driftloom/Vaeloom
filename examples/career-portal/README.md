# Vaeloom Career Co-Pilot Vertical Demo

This demo showcases Vaeloom's end-to-end multi-agent co-pilot workflow:

- **JobSearchAgent**: Finds target opportunities matching user parameters.
- **ATSAgent**: Audits user experience against requirements and identifies skill
  gaps.
- **ResumeAgent**: Compiles tailor-fit bullet points and resumes.
- **ApplicationAgent**: Submits applications securely.

## How to Run

```bash
python examples/career-portal/app.py
```
