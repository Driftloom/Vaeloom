## 2. Trust failure scenario map (prompt overlay)

| Scenario                                                 | Validated by | Counterexample test                                                                    |
| -------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------- |
| Wrong memory (assistant believes/asserts a wrong fact)   | VB-02, VB-07 | Correction loop: same error re-proposed after user correction = fail                   |
| Overreach (assistant acts beyond what the user approved) | VB-03        | Approval gate: any consequential action without payload-bound expiring approval = fail |
| Missed deadlines (extraction or reminder failure)        | VB-01        | Deadline extracted but not surfaced; surfaced but reminder missed = fail               |
| Confusing approvals (user cannot tell what/why/when)     | VB-03        | Drop-off at approval gate; un-explained payloads = fail                                |
| Difficult deletion (user cannot remove data fully)       | VB-05        | Purge leaves residue in any projection = fail                                          |

## 4. Leading indicators and stop/pivot (feed BQ-06)

Carried from prior run (DEC-P01-05, re-affirmed by USER 2026-08-13, BQ-06).
Thresholds are placeholders pending USER approval (EVD-MVP-P01-022):

- **Stop:** cohort churn > X% driven by trust events (unclear approvals, hard
  deletion, wrong memory) with no fix within N releases.
- **Pivot:** no repeat-input reduction after adoption (memory value absent) ->
  reconsider the memory-first wedge.
- **Pivot:** deadline extraction accuracy below Y% -> narrow to a
  document-focused wedge.
- **Leading indicator (trust):** approval-gate drop-off rate and correction rate
  trend over time; rising trends with no improvement = early trust alarm.
- **Leading indicator (ops):** deadline-miss events per user per week trending
  up despite reminders = ops/quality alarm.

X, Y and N: `REQUIRES_STAKEHOLDER_DECISION` - USER (BQ-06).
