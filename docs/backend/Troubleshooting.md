# Backend Troubleshooting

> **Purpose:** Fix the failures every new backend session hits **Owner:**
> Backend Team **Last Updated:** 2026-09-15

| #   | Symptom                                                        | Cause                                                                                                     | Fix                                                                                                                                                          |
| --- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Port 3000 in use / frontend won't start                        | Leftover `node` processes hold the port                                                                   | `Get-Process -Name "node" \| Stop-Process -Force`, then `pnpm dev:web`                                                                                       |
| 2   | Env vars ignored / DB still default Postgres                   | Pydantic `model_config` lacks `env_file` — `.env` is never read; or `DATABASE_URL` single-underscore used | Export in shell before launch; use `DATABASE__URL` (double underscore). See [Local-Development](./Local-Development.md)                                      |
| 3   | `403` on POST/PUT/PATCH/DELETE                                 | Missing CSRF header                                                                                       | `GET /csrf-token` first, send `X-CSRF-Token`. `/api/v1/auth/*` and `/csrf-token` are exempt (`SKIP_PREFIXES`/`SKIP_PATHS`)                                   |
| 4   | Boot refusal: `JWT_SECRET must be…`                            | Empty, < 32 chars, or known default                                                                       | `openssl rand -hex 32`; same rule for `ENCRYPTION_KEY`. Never use `AUTH_JWT_SECRET` (wrong name)                                                             |
| 5   | `SET app.workspace_id` / RLS errors on every query             | GUCs are fail-closed by design (`set_rls_session_vars`, `database.py`); missing tenant context            | Requests must carry workspace/user context via `TenantContext` (path/header → `app.workspace_id`, `app.user_id`, `app.tenant_id`). Unset = refused, not open |
| 6   | Full pytest run hangs under xdist                              | Known issue, finding 39                                                                                   | Per-file runs, or serial `-o addopts=""` (~8-10 min), or `-o addopts="-n auto --dist loadfile"` (~2-3 min, needs 32 GB). 16 workers ≈ 4-5 GB                 |
| 7   | `503` from `resumes/*/compile`, `/cover-letter`, `/cheatsheet` | Playwright Chromium not installed                                                                         | `uv run --project apps/api playwright install chromium` (one-time). 503 + setup hint is by design                                                            |
| 8   | `503` from `/temporal/*`                                       | Temporal down, durability requested                                                                       | Start Temporal or use non-durable endpoint; fail-closed is intentional                                                                                       |
| 9   | `pnpm dev` hangs forever                                       | Runs Nx `dev` across all 25 packages (most have no `dev` script)                                          | Always `pnpm dev:web` / `make dev-web` / `pnpm dev:be`                                                                                                       |
| 10  | API works via curl, fails in browser                           | CSP `connect-src` blocks `localhost:8000`                                                                 | Dev allow-list in `middleware.ts` + `next.config.js` (`NODE_ENV === 'development'`)                                                                          |
| 11  | camelCase/snake_case mismatch                                  | Backend serializes snake_case; only `api.ts`/`api-client.ts` transform _responses_                        | Request bodies stay snake_case; new clients need `transformKeys()`                                                                                           |
| 12  | Alembic drift / migration fails                                | Schema changed without migration, or destructive change                                                   | `alembic check`, `alembic downgrade -1`, `alembic upgrade head`; never edit prod schema directly                                                             |

> _Last verified: 2026-09-15._
