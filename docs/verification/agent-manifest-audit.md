# Agent Manifest & Zero-Trust Policy Audit

## 1. Compliance Finding

> [!CAUTION] **CRITICAL FINDING**: 0 out of 28 agents currently declare an
> `agent.yaml` manifest. All agent permissions, tools, and memory scopes are
> currently declared in Python class attributes (`BaseAgent` subclasses), which
> violates the fundamental zero-trust rule that authorization must be externally
> compiled and platform-enforced.

## 2. Agent Manifest Requirements Gap

Every agent requires a compiled `agent.yaml` specifying:

1. `identity`: Authenticated principal binding
2. `memory`: Explicit `read`, `write`, and `denied` scopes (preventing
   credentials/secrets access)
3. `tools`: Explicit `allow` and `deny` lists (no wildcard inheritance)
4. `delegation`: Allowed peer target agents and maximum depth limit
5. `approvals`: Actions requiring human approval vs automatic execution
6. `limits`: Max iterations, tool calls, tokens, USD cost, and timeout
