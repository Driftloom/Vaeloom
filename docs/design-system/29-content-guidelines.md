# 29. Content & Microcopy Guidelines

## 1. Tone and Voice

- **Direct and Precise**: Use concise, active voice. Avoid flowery corporate
  jargon or exaggerated AI enthusiasm.
- **Respectful and Calm**: Technical status messages should explain what
  happened, why it happened, and how to resolve it.
- **No Anthropomorphism**: Do not refer to Vaeloom or agents as "I", "me", or
  "your friendly assistant". Refer to specific agents by role: "Job Search Agent
  found 3 new listings", "Memory engine indexed 42 entities".

## 2. Standard Terminology

- Use **Ingest** for bringing data into the memory store.
- Use **Synthesize** for deriving insights or relationships across memories.
- Use **Authorize / Approve** for granting human permission to an agent
  proposal.
- Use **Connector** for external data integrations (Slack, Notion, Google
  Drive).
- Use **Run** for an agent execution instance.
