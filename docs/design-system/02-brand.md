# 02. Brand & Visual Identity

## 1. Brand Philosophy

Vaeloom is a memory-first personal intelligence workspace. Its brand identity
reflects calmness, trustworthiness, precision, and cognitive clarity.

Unlike consumer AI products that use vibrant purple gradients, rainbow accents,
or magical sparkles to imply intelligence, Vaeloom treats intelligence as an
engineering discipline:

- **No "AI Purples" or Neon Gradients**: Colors are restrained, functional, and
  grounded in slate, zinc, and muted obsidian tones.
- **No Sparkles (`✨`)**: Machine agency is indicated by semantic state
  indicators, confidence levels, and provenance citations—never decorative
  celestial glyphs.
- **High Contrast & Readability**: Information density is balanced with visual
  hierarchy, supporting extended daily focus for enterprise knowledge workers.

## 2. Color System Philosophy

The color system is organized into three distinct tiers:

1. **Base Neutral Scale (Zinc/Neutral)**: Used for canvases, surfaces, borders,
   dividers, and typography.
   - Dark Mode Canvas: `#08080a` (Vaeloom Obsidian)
   - Light Mode Canvas: `#f8f9fc` (Vaeloom Clean Slate)
   - High-Contrast Canvas: `#000000` (Pure Black)
2. **Primary Accent (Indigo/Blue)**: Used exclusively for interactive
   affordances and primary user actions (`#3b82f6` / `#2563eb`).
3. **Semantic Accents**:
   - Success / Verified: `#10b981` (Emerald)
   - Warning / Attention: `#f59e0b` (Amber)
   - Danger / Destruction: `#ef4444` (Rose)
   - AI / Agentic Process: `#6366f1` (Calm Slate-Indigo) - muted,
     non-distracting indicator of autonomous operations.

## 3. Typography Direction

- **Primary Interface Font**: Inter / Geist / system sans-serif stack
  (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`).
- **Code & Telemetry Font**: JetBrains Mono / Fira Code / monospace stack
  (`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`).
- Strict optical sizing, proportional tabular numbers for metrics
  (`font-variant-numeric: tabular-nums;`).

## 4. Logo & Iconography

- **Icon Grid**: 16x16, 20x20, 24x24 px pixel-aligned SVG strokes.
- **Stroke Width**: 1.5px standard, 2px for high-contrast accessibility.
- **Consistency**: All product icons originate from `@vaeloom/ui-kit/icons`,
  eliminating inline SVG discrepancies.
