# Modules 01–03 Threat Model (STRIDE / Zero-Trust)

**Audit Date:** 2026-09-20  
**Methodology:** STRIDE + NIST SP 800-207 Zero-Trust Threat Modeling

---

## 1. Threat Matrix

| Threat Category            | Specific Threat                               | Vector                                                                        | Zero-Trust Defense / Mitigation                                                                                                     | Verified In Test                                                                            |
| :------------------------- | :-------------------------------------------- | :---------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------ |
| **Spoofing**               | Forged Supabase JWT                           | Attacker sends token signed with arbitrary key or `alg: none`                 | Cryptographic signature validation against Supabase JWKS; fallback API check with bounded 2s timeout and 1-hour maximum expiration. | `test_reject_unsigned_supabase_jwt`                                                         |
| **Spoofing**               | SAML XML Signature Wrapping (XSW)             | Manipulated SAML assertion with detached signature                            | `signxml` XML signature enforcement validating referenced ID against Subject assertion.                                             | `test_saml_xml_signature_wrapping_rejection`                                                |
| **Tampering**              | Onboarding Step Tampering                     | Skipping required workspace setup or tampering post-completion                | `STEP_SEQUENCE` prerequisite enforcement + `is_completed` immutability guard in `onboarding_service.py`.                            | `test_onboarding_strict_step_progression`, `test_onboarding_immutable_post_completion`      |
| **Tampering**              | Resume Polyglot / Executable Upload           | Uploading PE / ELF / script disguised as PDF                                  | Magic byte verification: `%PDF-` for PDF, `PK\x03\x04` for DOCX, UTF-8 text validation; rejection of `MZ` / `\x7fELF`.              | `test_resume_magic_byte_spoofing_rejected`                                                  |
| **Repudiation**            | Unauthenticated Consent / Signup              | User denies agreeing to Terms of Service                                      | Mandatory `terms_accepted: true` at signup; cryptographic timestamp and IP address stored in `consent_records`.                     | `test_modules_01_03_comprehensive_zero_trust_gate`                                          |
| **Information Disclosure** | Cross-Tenant Workspace Enumeration            | User in Tenant A queries Workspace B or Org Tree B                            | `TenantContext` isolation + SQL queries filtered by `tenant_id` / `workspace_id` + PostgreSQL RLS.                                  | `test_cross_tenant_org_tree_isolation`, `test_agent_cross_workspace_memory_isolation`       |
| **Denial of Service**      | Login Brute Force / Password DoS              | High-frequency password attempts from single IP; 25,000-char password strings | `RateLimitMiddleware` (sliding window per IP) + Pydantic schema length constraints (max 128 chars).                                 | `test_login_rate_limiting_and_ip_throttling`, `test_password_edge_cases_and_dos_prevention` |
| **Elevation of Privilege** | Unauthorized Workspace Self-Join              | User B calls `/onboarding/join` with Workspace A UUID                         | Owner/invitation verification requiring pre-existing membership or ownership.                                                       | `test_unauthorized_workspace_join_rejected`                                                 |
| **Elevation of Privilege** | Viewer Inviting Workspace Members             | Viewer role invokes `POST /{ws_id}/invites`                                   | RBAC validation ensuring caller has `OWNER` or `ADMIN` role.                                                                        | `test_viewer_cannot_invite_workspace_member`                                                |
| **Elevation of Privilege** | Stolen Refresh Token Reuse                    | Attacker captures rotated refresh token and replays it                        | Family-based refresh token rotation: any reuse triggers instant revocation of all tokens in that family.                            | `test_concurrent_refresh_token_theft_defense`                                               |
| **Elevation of Privilege** | Post-Password-Reset Refresh Token Persistence | Attacker retains old refresh token after victim resets password               | `reset_password_with_token` explicitly executes `UPDATE auth_sessions SET status = 'REVOKED'` and sets `RevokedUserCutoff`.         | `test_password_reset_invalidates_active_refresh_tokens`                                     |
