# Vaeloom — Cross-Track Gate and Progression Policy

## Progression

1. MVP phases run 00→21. Phase 19 cannot authorize production without release evidence; Phase 20 validates real deployment; Phase 21 operates continuous improvement.
2. Continuation Phase 00 cannot begin merely because MVP documentation exists. It requires an approved MVP runtime handoff with user, trust, quality, security, deletion, restore, operational and product evidence.
3. Enterprise Phase 00 uses the continuation/pilot evidence as baseline. Greenfield enterprise work must explicitly justify bypassing continuation and still satisfy compatibility, data migration and consent-preservation obligations.
4. A score never overrides a mandatory blocker. `GO` requires ≥95/100 and zero blocker. `CONDITIONAL GO` is limited to explicitly non-dependent work. `NO-GO` triggers predecessor remediation.

## Cross-track release blockers

- Unproven workspace/tenant isolation or server-derived authorization context.
- Unlawful/unsupported connector or job-platform automation.
- Unbound, replayable or missing approval for consequential actions.
- Missing provenance, correction, export or deletion lifecycle.
- Critical prompt/tool/memory/identity or supply-chain risk.
- Missing representative test, restore, rollback, reconciliation, observability, support or incident evidence.
- Missing professional legal/privacy/compliance review where applicable.
- Fabricated, stale, non-reproducible or contradictory evidence.
